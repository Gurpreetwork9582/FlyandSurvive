**🐦 FlyToSurvive**

FlyToSurvive is a simple 2D survival game inspired by classic side-scrolling arcade mechanics. The objective is straightforward: control the bird, fight against gravity, and survive as long as possible.

This project was built to explore real-time game development concepts using Python and Pygame, including frame-rate independent movement, physics simulation, and object-oriented design.

**Controls**

Enter – Start the game

Space – Make the bird jump

**About the Project**

FlyToSurvive focuses on implementing core game development fundamentals rather than complex visuals. The game demonstrates:

A structured game loop (event handling → update → render)

Smooth motion using delta time (dt)

Gravity-based movement using velocity

Infinite scrolling background logic

Sprite-based character implementation

The bird’s movement is controlled through velocity changes, simulating gravity and jump mechanics for more realistic motion.


**Built With:**

Python

Pygame

Object-Oriented Programming principles

Git for version control


**Purpose**

This project was created as part of my learning journey in game development and to strengthen my understanding of:

Real-time rendering

Physics-based motion

Game loop architecture

Clean modular coding practices
